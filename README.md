
# 🔍 Tech Challenge — Fase 4  
## Modelo Preditivo - Peso Saudável 

Este repositório contém a entrega final do **Tech Challenge - Fase 4** do curso de pós-graduação em Data Analytics, no qual o objetivo principal foi desenvolver um modelo preditivo para auxiliar os médicos e médicas a prever se uma pessoa pode ter obesidade. 

---

## 🎯 Objetivo do Projeto

Desenvolver um modelo de Machine Learning com assertividade superior a 75% capaz de prever o nível de obesidade de um indivíduo, bem como disponibilizar essa solução por meio de:

- Uma pipeline completa de Machine Learning, documentada e reprodutível
- Uma aplicação preditiva interativa desenvolvida em Streamlit
- Um dashboard analítico com os principais insights sobre obesidade


---

## 📊 Fonte dos Dados

Os dados utilizados neste projeto estão disponíveis no arquivo obesity.csv, fornecido no contexto do Tech Challenge.

**Principais variáveis:**

Demográficas: idade, gênero, altura, peso
Hábitos alimentares: consumo de alimentos calóricos, vegetais, número de refeições
Estilo de vida: atividade física, consumo de água e álcool, uso de tecnologia
Outros fatores: histórico familiar de sobrepeso, meio de transporte

**Variável alvo:**

Obesity_level – classificação do nível de obesidade
